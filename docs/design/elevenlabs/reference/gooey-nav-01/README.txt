Gooey Nav Indicator — BYQ Gem

This is the gem's source folder, exactly as published:

  index.html + assets/…
    The real files. Paste the parts into your site, or open index.html to run
    it. When serving over http it works fully; opening it directly (file://)
    can block some WebGL/canvas effects — if so, run a local server, e.g.:

        npx serve
        # then open the printed http://localhost:… URL

  standalone.html
    One self-contained file (styles, script and media inlined). Open this if an
    effect doesn't run when you double-click index.html — it works from file://.

  AGENTS.md, gem.md
    Docs. AGENTS.md is a short integration guide for AI coding agents (Cursor,
    Claude Code, etc.); gem.md is the full tutorial with customization options.
